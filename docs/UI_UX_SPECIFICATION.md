# UI/UX Specification

**Status:** Not started; pending product discovery.

## Design objectives
- Make core granular sound-shaping controls fast to reach.
- Support both detailed sound design and immediate musical performance.
- Keep high-frequency performance controls accessible without burying advanced configuration.
- Provide clear visual feedback for sample position, grain activity, modulation and signal level.
- Preserve usability at common macOS display sizes and scaling settings.

## Areas to investigate
- Main instrument and layer navigation.
- Sample browser and sample editor.
- Waveform and spectrogram display.
- Grain visualization and parameter editing.
- Modulation routing interface.
- Sequencer and performance controls.
- Effects and preset browser.
- MIDI learn and parameter automation.
- Accessibility, keyboard navigation and visual scaling.

## Reference analysis
Do not assume the GR-MEGA's physical controls should be copied literally. Extract workflows and user needs, then design a native software interaction model.
